## Start here
1. Read `docs/01-PRD.md` for scope and user journeys.
2. Read `docs/02-DECISIONS.md` for accepted decisions and unresolved items.
3. Read `docs/03-ARCHITECTURE.md` and `contracts/01-API-CONTRACT.md` before scaffolding.
4. Execute `docs/05-BACKLOG.md` ticket-by-ticket using `antigravity/01-AGENT-GUIDE.md`.
5. Use `docs/06-RELEASE-CHECKLIST.md` before beta.

**Product:** Nichigo (approved name). Theme/visual requirements are specified in `docs/07-DESIGN-SYSTEM.md` and implemented in separate UI tickets.

## Files
- `docs/01-PRD.md`: requirements, MVP scope, UX, acceptance criteria.
- `docs/02-DECISIONS.md`: approved decisions, assumptions, unresolved choices.
- `docs/03-ARCHITECTURE.md`: technical architecture, data model, security, deployment.
- `docs/04-CONTENT-AND-LEARNING.md`: beginner-first curriculum and import governance.
- `docs/05-BACKLOG.md`: sequenced implementation tickets.
- `docs/06-RELEASE-CHECKLIST.md`: test and release gates.
- `docs/07-DESIGN-SYSTEM.md`: approved visual direction, CSS theming, light/dark/system and visual QA.
- `contracts/01-API-CONTRACT.md`: proposed REST endpoints and error conventions.
- `contracts/02-IMPORT-SCHEMA.md`: sample CSV/JSON contracts.
- `antigravity/01-AGENT-GUIDE.md`: safe agent workflow and first prompt.

**Important:** The project has not yet been implemented; all APIs/schemas are proposed contracts, not existing code. No user data, deployment, or GitHub repository is created by this pack.
