- `source/animcjk-c63765b/` — unmodified AnimCJK SVGs (keep headers) plus upstream `COPYING.txt` and `LGPL.txt`.
- `animcjk-kana.json` — generated by `scripts/kana-strokes/convert-animcjk.mjs`; a derivative of the above. Do not edit by hand.
